# Clip Brain Demo

当前只验证一个产品切片：24 小时自动焚毁的文本与文件剪贴板。分支为 `demo/clip-brain-v0`，未部署、未开 PR、禁止合并。

## 本地打开

在仓库根目录运行：

```powershell
py -3 -m http.server 4173 --bind 127.0.0.1 --directory demos\clip-brain
```

浏览器打开：

```text
http://127.0.0.1:4173/clipboard/
```

不要直接双击 `index.html`。`file://` 下 IndexedDB、剪贴板和下载权限可能表现不一致。

## 当前功能

- 一条记录包含文本、文件或两者；
- 文本上限 10000 个 Unicode 字符；
- 任意文件类型，每条最多 30 个文件、文件合计最多 1 GiB；
- 待保存文件固定在 210px 高度的滚动托盘中，不再把整页向下撑长；
- 待保存和已保存文件均显示原始文件名、后缀标签与大小；
- 删除不再调用浏览器原生确认框；第一次点击只把按钮改成“再点一次”，第二次才执行；
- IndexedDB 保存，创建 24 小时后自动删除；
- 同一浏览器标签页同步数据，但不强制同步页面导航；
- 每页最多 12 条，文本三行预览、文件默认只显示四个；
- “选择本页”整行已移除；勾选条目后，右上角才出现紧凑的“已选 N 条”；
- 该按钮停留约 260ms 才瞬时展开“全部复制 / 下载”和“全部焚毁”；
- 纯文字选择高亮“复制”；只要含文件就高亮“下载”；
- ZIP 内容不满 256 MiB 时使用浏览器普通下载，会出现在浏览器下载记录；
- ZIP 内容超过 256 MiB、但仍严格小于 1 GiB 时改用本地流式直存，避免整包驻留内存；直存不会出现在浏览器下载记录；
- 服务器不参与压缩，也不保存 ZIP。

## 自动测试

需要 Python 3 与 Node.js：

```powershell
py -3 -m unittest discover -s demos\clip-brain\tests -p "test_*.py" -v
```

测试覆盖：

- 所有前端文件低于 300 行停止线；
- JavaScript 语法；
- HTML 双入口、分页、紧凑选择菜单及仅两个批量动作；
- 选择菜单延时与无动画契约；
- 不存在 `window.confirm`；
- 待上传文件滚动托盘与空状态隐藏；
- 真实 ZIP、CRC、中文文本、文件内容和危险文件名清理；
- 256 MiB 以下走浏览器下载，以上走本地直存；
- 打包总量等于 1 GiB 时必须拒绝；
- 批量焚毁只提交明确选择的 ID。

## Demo 不能证明什么

- 不代表生产 `/clipboard` 已部署；
- 不支持跨设备或跨浏览器同步；
- 浏览器实际可用空间可能小于 1 GiB，配额不足会明确失败；
- 不包含公网分享、二维码、AI、搜索、分类、预览或永久保存。
