# Clip Brain 产品边界

> 本文件是 Clip Brain 的边界事实入口。2026-07-29 按 Owner 决策同步：
> v0 Demo 的分页、纯本地 IndexedDB、「只有两个批量动作」等表述已作废并删除。

## 一句话定义

Clip Brain 是与 CMX/Mastodon 同域并列的临时剪贴板页面，用于短期搬运文本和文件。
条目默认在创建 24 小时后自动焚毁；被 ★ 收藏的条目不焚毁，但一并受账户总配额约束。

## 与 CMX 的关系

- 同一站点、同一登录态：Mastodon 根路径 `/` 承载时间线和嘟文，Clip Brain 位于 `/clipboard/`；
- Clip Brain 内容不创建 status，不进入时间线，不进入联邦，不写 Mastodon PostgreSQL；
- 右上角标识是**门牌**：本站只显示自己那一面，点一下切到对面站点，两面不同时出现；
- 后端复用现有 `cmx-mcp-http` Starlette 进程与 Nginx 同源入口，不新增第四套 Web 服务。

## 数据边界

服务端为唯一事实源（独立 SQLite + 独立对象目录，不复用 `filebox_files`，不复用 Mastodon media/status）：

```text
clip entry
├─ entry_id
├─ owner_account_id            按 Mastodon 账号隔离
├─ text                        0..10000 Unicode code points
├─ files                       0..20 个任意类型文件
├─ created_at
├─ expires_at                  created_at + 24h；收藏后为 NULL
├─ favorited_at                NULL = 临时
└─ topic                       手动主题标签，NULL = 未归类
```

- 每条：文本 UTF-8 字节 + 文件字节合计**严格小于 1 GiB**；
- 每账户：总量上限 **2 GiB**，收藏条目一并计入；
- 容量计平时不显示，仅在用量超过 1.5 GiB 时出现；
- 达到 2 GiB 时**拒绝新建**，不自动删除旧内容；
- `expires_at` 只由服务器计算，忽略客户端传值。

**2 GiB 是硬顶，也是 Clip Brain 不会退化成永久云盘的结构性保证。**

## 本地下载边界

- 单文件下载由服务端以 `Content-Disposition: attachment` + `nosniff` 直出；
- 单条与多选打包仍在 Owner 当前浏览器内完成，服务器不生成也不保存 ZIP；
- ZIP 使用 STORE 模式流式写入本地文件，不在内存中拼出完整 Blob；
- 参与打包的文字按 UTF-8 字节计入，合计必须严格小于 1 GiB；
- 文件名只作为显示名与下载名，必须清理路径分隔符、控制字符和 CR/LF；
- 磁盘路径只由服务端生成的 ID 决定，客户端不得提供路径；
- 不解压用户文件，不执行也不预览其中内容；
- 公网分享码、二维码和匿名下载已于 Issue #26 明确取消。

## 页面边界

- 无分页，条目区单一滚动；每条内部文件列表独立滚动；
- 右上角「N 条」胶囊是**唯一批量入口**，悬停或点击展开，三个动作：全部复制 / 全部下载 / 全部焚毁；
- 无勾选时作用于当前视图全部，有勾选时只作用于勾选项；
- 焚毁为按钮内二次确认，不调用浏览器原生 `confirm()`；
- 双击正文即复制，不设复制按钮；
- 亮 / 暗两套主题，滚动条隐形，无 `transition`、无 `animation`；
- 选择状态只属于当前标签页；内容、删除和到期结果跨设备一致。

## 明确不是

- 不是 NAS 或永久云盘（2 GiB 硬顶）；
- 不是 CMX 时间线附件区；
- 不是 AI 任务中枢：不做摘要、识图、语义检索或**自动分类**；
- 不是公网文件分享服务；
- 不是文件预览器、编辑器或版本管理器。

> 注意区分：**手动**给条目打主题标签属于范围内；**自动**归类、自动打标、自动总结不在范围内。
> 同理，**关键词**检索属于范围内；语义/向量检索不在范围内。

## 代码边界

- 页面结构、基础视觉、组件视觉、后端 adapter、存储、ZIP、渲染和交互分别维护；
- 任一前端文件或新增 Python 模块达到 300 行前必须先拆分；
- 不把功能继续塞进 `remote.py` 或单一前端总控文件；
- 不修改 `LOCAL_DOMAIN`，不执行 `docker compose down -v`、清卷或 prune，不触碰 Mastodon 数据卷；
- 未经 Owner 体验验收和只读测试，不得开 PR 或合并。
