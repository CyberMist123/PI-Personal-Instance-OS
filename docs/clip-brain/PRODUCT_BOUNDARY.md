# Clip Brain 产品边界

## 一句话定义

Clip Brain 是与 CMX/Mastodon 并列的临时剪贴板页面，用于短期搬运文本和文件；每条记录在创建 24 小时后自动删除。

## 与 CMX 的关系

- 同一站点，目标路径为 `/clipboard`；
- Mastodon 根路径继续承载时间线和嘟文；
- Clip Brain 内容不创建 status，不进入时间线；
- 右上角品牌入口只做页面导航，不让一个标签页强制切换另一个标签页；
- 两边未来可以共用登录态，但 Demo 不实现鉴权、后端或生产路由。

## 当前数据边界

Demo 仅使用浏览器 IndexedDB：

```text
clip entry
├─ id
├─ text (0..10000 Unicode code points)
├─ files (0..30 arbitrary file blobs)
├─ createdAt
└─ expiresAt = createdAt + 24h
```

每条文件总量上限为 1 GiB。浏览器配额可能更低；配额不足必须失败，不得显示幽灵成功记录。

## 本地下载边界

- 单文件下载直接从 IndexedDB Blob 写入浏览器下载；
- 单条和多选打包只在 Owner 当前浏览器内完成；
- ZIP 使用 STORE 模式流式写入用户选定的本地文件，不上传服务器，也不在内存中拼出完整 ZIP Blob；
- 参与打包的文字按 UTF-8 字节计入，文字与文件合计必须严格小于 1 GiB；
- 文件名只作为 ZIP 内显示名，必须清理路径分隔符、控制字符和危险尾缀；
- 不解压用户文件，不执行或预览其中内容；
- 公网分享码、二维码和匿名下载已明确取消。

## 页面密度边界

- 每页最多 12 条；
- 正文默认只显示三行；
- 每条默认只显示四个文件，其余按需展开；
- 选择状态只属于当前标签页，不跨窗口同步；
- 内容数据、删除和到期结果继续跨同浏览器标签页同步。

## 明确不是

- 不是 NAS 或永久云盘；
- 不是 CMX 时间线附件区；
- 不是 AI 任务中枢；
- 不是知识库、搜索引擎或自动分类器；
- 不是公网文件分享服务；
- 不是文件预览器、编辑器或版本管理器。

## 代码边界

- 页面结构、基础视觉、组件视觉、存储、ZIP、渲染和交互分别维护；
- 任一前端文件达到 300 行前必须先拆分；
- Demo 不修改 Mastodon、MCP、Nginx、compose 或生产数据；
- 未经 Owner 体验验收和 Claude 只读测试，不得开合并 PR。
