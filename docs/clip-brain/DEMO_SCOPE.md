# Clip Brain v0 Demo Scope

## 目标

一天内验证：独立黄色 Clip Brain 页面是否比把临时内容塞进 CMX 时间线更自然。

## 唯一功能

1. 添加文本、任意文件，或两者组合；
2. 文字最多 10000 个 Unicode 字符；
3. 每条最多 30 个文件，总量最多 1 GiB；
4. IndexedDB 保存和 24 小时过期清理；
5. 同一浏览器标签页同步新增、删除和到期结果；
6. 点击正文复制，点击文件下载；
7. 手动焚毁整条记录；
8. 右上角 Mastodon / Clip Brain 双入口；
9. 无动画、立即渲染；
10. 原创高对比喷墨贴纸视觉，不使用任何现成游戏素材。

## 停止线

以下任何一项出现时立即停止扩展：

- 想加入搜索、标签、分类或排序；
- 想加入 AI、MCP 或自动总结；
- 想加入永久保存、转嘟文或分享链接；
- 想修改 Nginx、Mastodon 或生产启动链；
- 任一前端文件接近 300 行却没有先拆分。

## 人工验收

- [ ] `http://127.0.0.1:4173/clipboard/` 正常打开；
- [ ] 10000 字成功，10001 字拒绝；
- [ ] 30 个文件成功，31 个拒绝；
- [ ] 总量超过 1 GiB 时在写入前拒绝；
- [ ] 配额不足时显示失败且列表无幽灵记录；

- [ ] 点击文本复制完整内容；
- [ ] 点击文件下载原始 Blob；
- [ ] 过期记录从界面和 IndexedDB 删除；
- [ ] Mastodon 时间线未被写入任何 Clip Brain 内容；
