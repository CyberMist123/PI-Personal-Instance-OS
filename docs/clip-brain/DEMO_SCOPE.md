# Clip Brain v0 Demo Scope

## 目标

验证独立黄色 Clip Brain 页面是否比把临时内容塞进 CMX 时间线更自然，同时保持代码和数据边界足够小。

## 唯一功能

1. 添加文本、任意文件，或两者组合；
2. 文字最多 10000 个 Unicode 字符；
3. 每条最多 30 个文件，文件总量最多 1 GiB；
4. IndexedDB 保存和 24 小时过期清理；
5. 同一浏览器标签页同步新增、修改、删除和到期结果；
6. 文件显示原始文件名、后缀标签和大小；
7. 保存前移除单个文件，保存后删除单个文件；
8. 点击正文复制，点击文件下载；
9. 每页最多 12 条；文本三行预览，文件默认展示四个；
10. 单条或多选条目在本地流式生成 ZIP；
11. 选中条目后只展开两个批量动作：自适应复制/下载，以及全部焚毁；
12. 纯文本选择合并复制；只要含文件就下载所选 ZIP；
13. 批量焚毁经二次确认后，用一个 IndexedDB 事务删除明确选择的条目；
14. 批量复制或打包按 UTF-8 文本字节与文件字节合计，必须严格小于 1 GiB；
15. 手动焚毁整条记录；
16. 右上角 Mastodon / Clip Brain 双向入口；
17. 无动画、立即渲染；
18. 原创高对比喷墨贴纸视觉，不使用现成游戏素材。

## 明确不做

- 公网分享码、二维码、匿名下载或公开链接；
- 跨设备服务器同步；
- AI、MCP、搜索、标签、分类和自动总结；
- 永久保存、转嘟文或分享链接；
- 文件预览、在线编辑或版本历史；
- Nginx、Mastodon、compose、生产启动链或运行数据修改。

## 代码停止线

```text
demos/clip-brain/clipboard/
├─ index.html       页面骨架
├─ styles.css       页面基础视觉
├─ components.css   列表、菜单、分页与选择控件
├─ storage.js       IndexedDB 与过期清理
├─ archive.js       本地流式 ZIP
├─ downloads.js     单文本复制与单文件下载
├─ bulk.js          批量复制、打包与焚毁
├─ view.js          渲染与分页
└─ app.js           状态和交互编排
```

- 任一前端文件达到 300 行前必须先拆分；
- 不把 ZIP、分页、下载或批量动作继续塞回一个总控脚本；
- 新功能超出上方“唯一功能”时先停工，不顺手扩 scope。

## 自动验收

```powershell
py -3 -m unittest discover -s demos\clip-brain\tests -p "test_*.py" -v
```

自动测试必须验证：JS 语法、HTML 契约、无动画、文件行数、ZIP 可读性、CRC、内容一致、危险文件名清理、纯文本/含文件动作分流、批量 ID 删除，以及 1 GiB 严格拒绝。
