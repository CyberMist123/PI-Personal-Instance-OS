# Clip Brain v0 Demo Scope

## 目标

验证独立黄色 Clip Brain 页面是否比把临时内容塞进 CMX 时间线更自然，同时保持代码和数据边界足够小。

## 唯一功能

1. 添加文本、任意文件，或两者组合；
2. 文字最多 10000 个 Unicode 字符；
3. 每条最多 30 个文件，文件总量最多 1 GiB；
4. IndexedDB 保存和 24 小时过期清理；
5. 同一浏览器标签页同步新增、修改、删除和到期结果；
6. 文件显示原始文件名、后缀标签和大小；
7. 待上传文件放进固定高度滚动托盘，不让文件数量把整页撑长；
8. 保存前移除单个文件，保存后删除单个文件；
9. 删除采用按钮内二次确认，不调用浏览器原生 `confirm()`；
10. 点击正文复制，点击文件普通下载；
11. 每页最多 12 条；文本三行预览，文件默认展示四个；
12. 移除“选择本页”整条工具栏；勾选后只在标题右侧显示“已选 N 条”；
13. “已选 N 条”停留约 260ms 才瞬时展开，鼠标离开约 220ms 后收起；
14. 选择菜单只允许两个动作：自适应“全部复制 / 下载”和“全部焚毁”；
15. 纯文本选择高亮“复制”并合并复制；只要含文件就高亮“下载”；
16. ZIP 不满 256 MiB 时走浏览器普通下载并进入下载记录；
17. ZIP 超过 256 MiB、但严格小于 1 GiB 时走 File System Access API 流式直存；
18. ZIP 生成期间下载高亮位原地显示百分比，菜单不得中途收起；
19. 批量焚毁需要同一按钮二次点击，并用一个 IndexedDB 事务删除明确选择的条目；
20. 批量复制或打包按 UTF-8 文本字节与文件字节合计，必须严格小于 1 GiB；
21. 右上角 Mastodon / Clip Brain 双向入口；
22. 无 transition / animation，页面和菜单均立即渲染；
23. 原创高对比喷墨贴纸视觉，不使用现成游戏素材。

## 明确不做

- 公网分享码、二维码、匿名下载或公开链接；
- 跨设备服务器同步；
- AI、MCP、搜索、标签、分类和自动总结；
- 永久保存、转嘟文或分享链接；
- 文件预览、在线编辑或版本历史；
- Nginx、Mastodon、compose、生产启动链或运行数据修改。

## 代码停止线

```text
demos/clip-brain/clipboard/
├─ index.html           页面骨架
├─ styles.css           页面基础视觉
├─ components.css       文件、卡片和分页组件
├─ compact-layout.css   待上传滚动区和隐藏状态修正
├─ selection-menu.css   选择菜单视觉
├─ storage.js           IndexedDB 与过期清理
├─ archive.js           ZIP 编码与流式写入
├─ archive-output.js    浏览器下载 / 本地直存分流
├─ downloads.js         单文本复制与单文件下载
├─ destructive.js       按钮内二次确认
├─ bulk.js              批量复制、打包与焚毁
├─ selection-menu.js    延时展开、模式高亮与 ZIP 进度
├─ view.js              渲染与分页
└─ app.js               状态和交互编排
```

- 任一前端文件达到 300 行前必须先拆分；
- 不把 ZIP、分页、下载、删除确认或选择菜单继续塞回一个总控脚本；
- 新功能超出上方“唯一功能”时先停工，不顺手扩 scope。

## 自动验收

```powershell
py -3 -m unittest discover -s demos\clip-brain\tests -p "test_*.py" -v
```

自动测试必须验证：JS 语法、HTML 契约、无动画、无原生确认框、文件行数、紧凑选择菜单、待上传滚动托盘、ZIP 可读性、CRC、内容一致、危险文件名清理、浏览器下载/本地直存分流、批量 ID 删除，以及 1 GiB 严格拒绝。
