语音条 · 定稿 无底色，随主题反色

楷体只在系统装了它时生效：Windows 是 KaiTi/楷体，macOS 是 Kaiti SC/STKaiti，两边都自带。 iOS 和 Android 通常没有楷体，会退到平台衬线体——字重和手写感接近，但笔形不是楷。 如果你要求手机上也必须是楷，那就得自己托管一个楷体 web font，代价是几 MB 的中文字体文件，我不建议为一句转写付这个流量。

正文样例：你好 天道，明天早上先把备份跑一遍。

反色而非白底：整条只用一个 --ink，日间是墨黑、夜间是暖白，波形、播放键、播放头共用它。 所以夜间不再有一张白纸浮在时间线上，两种主题是同一种克制。 倍速已移除，播放键放大到 46px（图标 26px）。
